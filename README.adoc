= Hledger grammar

An ANTLR grammar for partial support of https://hledger.org/[hledger] journal files.

== Support
This grammar supports only a subset of the constructs of an hledger journal.

I do not intend to extend it for now (and possibly ever), but I welcome help if anyone wants to contribute for supporting more syntax.
